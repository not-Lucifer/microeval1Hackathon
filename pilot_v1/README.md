# Pilot on task set v1 (2026-10-31)

This folder keeps the calibration pilot that was run on the **first version** of the eight
tasks (v1). It is the evidence for why the tasks were replaced by harder ones (v2, the
current `tasks/`). Nothing here counts toward the v2 results.

| Folder | What it holds |
|---|---|
| `transcripts/` | every v1 answer: the first OpenRouter run (paid, mostly stopped by HTTP 402 "out of credits"), the free OpenRouter run, and ChatGPT web replies pasted by hand |
| `manual/chatgpt-free/` | the ChatGPT replies exactly as pasted, plus `info.yaml` (app, mode, date, confirmations) |
| `results/summary.md`, `results/scorecard.json` | the pilot scoreboard, generated by `scripts/report.py` |

**What the pilot showed** (numbers in `results/summary.md`): every model answering through
the API passed almost every v1 task it reached. The only failures were Task 08 truncations
(the model used its whole token budget) and the ChatGPT free-plan replies with Think off.
An eval of "what AI can't do yet" needs headroom, so each task family was kept but its
instance was made harder (`docs/OPEN_QUESTIONS.md` items 35-38, `docs/PROJECT_GUIDE.md` §5).

**API errors** (`API_ERROR`, excluded from every score): almost all are HTTP 402 from the paid
run (the account was out of credits), plus `inkling:free` (403, the model is only served to
listed apps) and Gemma's busy free provider (429).

## Re-grading the pilot

These transcripts answer the v1 prompts, so the current code refuses to grade them (it would
compare old answers with new tasks). The commit that holds v1 is tagged `pilot-v1`:

```bash
git checkout pilot-v1
python run_eval.py --regrade transcripts/   # 0 grades differ
git checkout main
```
